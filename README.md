# SmartLead AI

Pine & Pour projesi için hazırlanan SmartLead AI çalışmasının kaynak kodlarını içerir.

Proje Python ve Flask kullanılarak oluşturuldu. Amaç, kullanıcıların marka hakkında temel sorular sorabileceği ve gerektiğinde iletişim bilgilerinin alınabilmesidir.

Projedeki dosyalar:
"run.py" uygulamayı başlatır
"config.py" proje ayarlarını içerir
"app/routes.py" istekleri yönlendirir
"app/database.py" veritabanı işlemlerini içerir
"app/services/ai_service.py" yapay zeka API bağlantısını içerir
"app/templates" arayüz dosyalarını içerir

Gerekli paketler:
"pip install -r requirements.txt"
Uygulamayı çalıştırmak için:
python run.py
